========================================
  个人网站项目 · 上交材料说明
========================================

本压缩包解压后包含 3 部分：

【1】网站_直接打开/    ← 最重要的！双击 index.html 即可直接看到网站
    里面是"自包含"版本：JS/CSS 已全部内嵌进 index.html，
    图片（头像/证书）、音乐、OpenCV 资源都在同目录，
    不需要安装任何软件、不需要联网，双击就能看。

【2】个人网站项目源码.html
    HTML 格式源码文档，内含所有源码（含游戏代码）：
    贪吃蛇 SnakeGame / 爬虫 CrawlerDemo / 视觉识别 VisionDemo，
    以及全部 React 组件、样式、数据、Python 参考代码。

【3】项目源码/        ← 完整可运行的项目工程（开发用）
    运行方式：进入该目录执行
      npm install
      npm run dev
    然后浏览器打开 http://localhost:5173/

线上地址：https://neverlone888.github.io/

提示：网站_直接打开 里的视觉识别（OpenCV）和摄像头功能
需要服务器环境才能使用，其余功能（页面/图片/音乐/游戏）双击即可正常查看。
